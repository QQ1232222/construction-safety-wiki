# S7：營建墜落風險高，掌握關鍵才能有效預防

## 重點摘要
- 營造業占重大職業災害比率長年居各產業首位（S7, p.1）
- 近年營造業墜落職災死亡比例高達 60~70%（近年，未標示具體期間，S7, p.1）
- 墜落媒介物以施工架、模板支撐、鋼構、電梯井、吊料設備為主（S7, p.1）
- 以 80/20 法則分析，確立三項關鍵要因：配置不當、本體防護不足或無安全設施、性能及強度不足（S7, p.1）
- 規劃五項職能課程（預知力、配置力、設置力、穿戴力、檢驗力）（S7, p.1）
- 編撰「營建工程關鍵要因導向之墜落災害預防技術指引」（S7, p.2）

## 關鍵數據
| 指標 | 數值 | 期間 | 來源 |
|------|------|------|------|
| 營造業墜落職災死亡比例 | 60~70% | 近年（未標示具體期間） | S7, p.1 |

## 三項關鍵要因（S7, p.1）
依 80/20 法則分析墜落職災案例，確定三項防災預防重點：
1. **配置不當** — 施工現場設備與設施的配置規劃有誤
2. **本體防護不足或無安全設施** — 欠缺護欄、安全網、個人防護具等
3. **性能及強度不足** — 防護設施未達應有強度與性能要求

## 五力職能訓練（S7, p.1）
針對關鍵預防控制措施規劃五項職能課程：
| 職能 | 說明 |
|------|------|
| 預知力 | 墜落危害辨識 |
| 配置力 | 四度空間規劃設計 |
| 設置力 | 墜落預防關鍵設施之設置 |
| 穿戴力 | 預防墜落之個人防護具穿戴 |
| 檢驗力 | 關鍵設施之檢驗 |

## 研討會展示內容（S7, p.1）
- 系統式施工架之應用及其安全設施
- 營建工程墜落預防關鍵安全設施與防護具設置確認
- 科技防災墜落預防輔助
- 防墜安全設施及錨錠裝置之功能與性能測試
- 鋁合金系統式施工架構件輕量化及墜落防護之規劃

# 營造安全衛生設施標準：墜落防護（Fall Protection under Construction Safety Standards）

## 定義
《營造安全衛生設施標準》（S6）為台灣針對營造作業訂定之法規，以條文形式規定雇主在施工現場必須設置的各項安全設施與管理措施。本頁彙整與**墜落、飛落災害防止**及**施工架**、**個人防護具**相關的條文，並保留各條條號以便核對。

---

## 一、墜落、飛落災害防止（S6 第二章）

### 第 11-1 條：安全帽強制配戴（S6, p.3）
雇主對於進入**營繕工程工作場所**作業人員，應提供適當安全帽，並使其正確戴用。

### 第 17 條：墜落災害防止計畫（S6, p.5）
高度二公尺以上之工作場所，勞工作業有墜落之虞者，應訂定墜落災害防止計畫，依下列**風險控制優先順序**採取設施：

| 優先順序 | 措施 |
|---------|------|
| 1 | 由設計或工法之選擇，儘量使勞工於地面完成作業 |
| 2 | 優先施作永久構造物之上下設備或防墜設施 |
| 3 | 設置護欄、護蓋 |
| 4 | 張掛安全網 |
| 5 | 使勞工佩掛安全帶 |
| 6 | 設置警示線系統 |
| 7 | 限制作業人員進入管制區 |
| 8 | 因開放邊線、組模、收尾作業增加危險者，訂定保護計畫 |

### 第 18 條：屋頂作業（S6, p.5–p.6）
- **斜度 > 34 度**（高底比 2:3 以上）或滑溜屋頂：應設護欄、寬度 ≥ 40 公分工作臺及梯子；無法設護欄者，應提供背負式安全帶並掛置於堅固錨錠或安全母索
- 易踏穿材料構築之屋頂：應設屋架上寬度 ≥ 30 公分踏板通道，並於下方裝設堅固格柵或安全網

### 第 18-1 條：新建工廠鋼構屋頂（S6, p.6）
- 屋頂邊緣及屋頂突出物頂板周圍，設高度 ≥ 90 公分女兒牆或欄杆
- 易踏穿材料屋頂：設寬度 ≥ 30 公分通道，採光範圍下方設堅固格柵

### 第 19 條：高度 2 公尺以上護欄、護蓋或安全網義務（S6, p.6）
高度 ≥ 2 公尺的屋頂、鋼梁、開口部分、階梯、樓梯、坡道、工作臺、擋土牆、擋土支撐、施工構臺、橋梁墩柱、橋梁上部結構等，勞工有墜落之虞者，**應設護欄、護蓋或安全網**；設置困難或需臨時開啟者，應使勞工使用安全帶。

### 第 20 條：護欄規格（S6, p.7）
| 規格項目 | 要求 |
|---------|------|
| 上欄杆高度 | ≥ 90 公分 |
| 中欄杆 | 上下開口不得超過 55 公分 |
| 護欄強度 | 任何方向施加 75 公斤荷重，無顯著變形 |
| 鋼管直徑 | ≥ 3.8 公分 |
| 杆柱間距 | ≤ 2.5 公尺 |

### 第 21 條：護蓋規格（S6, p.7–p.8）
- 能承受人員及車輛通過之強度
- 有效防止滑溜、掉落、掀出或移動
- 柵狀構造：柵條間隔 ≤ 3 公分
- 臨時性開口護蓋：表面漆**黃色**並書警告訊息

### 第 22 條：安全網規格（S6, p.8）
| 規格項目 | 要求 |
|---------|------|
| 材料與強度標準 | CNS 14252 或 CNS 16079-1/16079-2 |
| 工作面至安全網之攔截高度 | ≤ 7 公尺 |
| 攔截高度 > 3 公尺時最小延伸距離 | ≥ 4 公尺 |
| 定期檢查頻率 | 每週一次 |

### 第 23 條：安全帶及安全母索（S6, p.8–p.9）
| 規格項目 | 要求 |
|---------|------|
| 安全帶適用標準 | CNS 7534、CNS 6701、CNS 14253、CNS 14253-1 |
| 安全母索最小斷裂強度 | ≥ 2300 公斤 |
| 錨錠承受拉力（每人） | ≥ 2300 公斤 |
| 使用前/衝擊後 | 應進行檢查，磨損劣化者禁用 |
| 禁止繫掛位置 | 護欄杆件（除非強度符合 2300 公斤）|

### 第 24 條：警示線管制通行區（S6, p.9）
- 適用條件：坡度 < 15 度，且距開口 > 2 公尺時，可以警示線代替護欄
- 杆柱間距：≤ 2.5 公尺；杆柱高度：≥ 90 公分
- 警示繩帶：黃色或紅色，設於杆柱頂端及二分之一高度處，最小張力強度 ≥ 225 公斤

### 第 25 條：開口封閉護蓋（S6, p.10）
廢止使用之開口應予封閉；暫不使用之開口應加蓋，以防止勞工墜落。

### 第 26 條：飛落物件固定（S6, p.10）
置放於高處，**位能超過 12 公斤‧公尺**之物件有飛落之虞者，應予固定。

### 第 27 條：覆網攔截飛落物（S6, p.10）
設置覆網攔截位能 < 12 公斤‧公尺之物件時：
- 方形或菱形網目任一邊長 ≤ 2 公分
- 強度應能承受直徑 45 公分、重 75 公斤之物體自高度 1 公尺處落下之衝擊力

## 二、施工架（S6 第四章）

### 第 39 條：施工架設置義務（S6, p.12）
不能藉高空工作車或其他方法安全完成之 **≥ 2 公尺高處**營造作業，應設置適當施工架。

### 第 40 條：施工架設計要求（S6, p.12）
下列施工架須由**專任工程人員或執業技師**依結構力學設計，置備施工圖說及強度計算書並簽章：
- 施工構臺
- 懸吊式施工架
- 懸臂式施工架
- **高度 ≥ 7 公尺且立面面積 ≥ 330 m²** 之施工架
- 高度 ≥ 7 公尺之吊料平臺

### 第 41 條：施工架組配作業主管（S6, p.12）
下列施工架之組配及拆除，應指派**施工架組配作業主管**於現場指揮：
- 懸吊式施工架
- 懸臂式施工架
- **高度 ≥ 5 公尺**之施工架

### 第 42 條：施工架組配作業注意事項（S6, p.13）
1. 強風、大雨、大雪等惡劣天候有危險之虞時，應即**停止作業**
2. 紮緊、拆卸及傳遞構材時，設寬度 **≥ 20 公分**踏板，使勞工使用安全帶
3. 吊升或卸放材料時，使用吊索、吊物專用袋

### 第 43 條：施工架材料規定（S6, p.13）
- 不得有顯著損壞、變形或腐蝕
- 鋼材等金屬材料應符合 **CNS 4750** 鋼管施工架同等以上抗拉強度

### 第 44 條：施工架保養（S6, p.13）
施工架應經常保養，維持牢穩。

### 第 45 條：施工架與構造物連接（S6, p.14）
施工架應與構造物妥實連接，間距：
- 垂直方向 ≤ **5.5 公尺**
- 水平方向 ≤ **7.5 公尺**

不得與模板支撐連接；基礎地面應平整夯實。

### 第 47 條：禁止在施工架上使用梯子（S6, p.14）
雇主不得使勞工在施工架上使用梯子、合梯或踏凳等從事作業。

### 第 48 條：施工架工作臺規定（S6, p.14–p.15）
高度 ≥ 2 公尺施工架上作業：

| 項目 | 規格 |
|------|------|
| 工作臺寬度 | ≥ 40 公分 |
| 踏板 | 鋪滿密接 |
| 踏板縫隙 | ≤ 3 公分 |
| 工作臺位置 | 低於立柱頂點 ≥ 1 公尺 |

### 第 51 條：施工架人員上下設備（S6, p.15）
施工架任一處步行至最近上下設備之距離 ≤ **30 公尺**。

### 第 52 條：施工架防止物體飛落（S6, p.15）
鄰近結構物周遭或跨越工作走道之施工架，應於下方設**斜籬及防護網**，以防止物體飛落。

### 第 59 條：鋼管施工架壁連座間距（S6, p.18–p.19）
| 施工架種類 | 垂直方向 | 水平方向 |
|-----------|---------|---------|
| 單管施工架 | 5 公尺 | 5.5 公尺 |
| 框式施工架（高度 ≥ 5 公尺） | 9 公尺 | 8 公尺 |

### 第 60 條：單管式鋼管施工架（S6, p.19）
- 立柱縱向間距 ≤ 1.85 公尺，梁間方向 ≤ 1.5 公尺
- 橫檔垂直間距 ≤ 2 公尺
- 立柱載重限制：400 公斤

### 第 60-1 條：系統式施工架（S6, p.19）
立柱、橫桿及斜撐應以輪盤、八角盤或類似構件及插銷扣件連接成緊密牢固之系統構架；交叉處不得以活扣或鐵線代替。金屬材料應符合 CNS 4750，輪盤等應採 SS400 或同等以上抗拉強度材質。
